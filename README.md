# ChargeShield: Securing EV Charging Infrastructure

Springer LNCS article (Overleaf) on verifying security problems in electric-vehicle charging infrastructure and overcoming the limits of existing market tools.

- `main.tex` – article source (pdfLaTeX, `llncs` class)
- `references.bib` – bibliography (`splncs04` style)

To open in Overleaf: New Project → Import from GitHub, or upload these files.
